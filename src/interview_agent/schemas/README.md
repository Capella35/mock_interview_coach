# schemas/

The Pydantic contracts every component speaks: today the **Fact Sheet** (`SourceDocument`, `Fact`, `JobRequirement`, `Discrepancy`, `FactSheet`) and the **Match / Gap Map** (`MatchEntry`, `MatchGapMap`) in `models.py`, plus the untrusted LLM **proposals** (`FactProposal`, `RequirementProposal`) in `proposals.py`, which carry a quote but no offsets or ids; the **Debrief Summary Card** joins in a later milestone, once the interviewer exists. **Rule: model output that does not match a schema is rejected, not trusted** — LLM responses are parsed into these models and anything that fails validation (bad shape, quote not found in the source, metric not in its quote, match without evidence) is dropped and reported, never silently repaired. Every Fact Sheet records the model (`extraction_model`) and prompt versions (`prompt_ids`) that produced it. Schema changes need a matching test change in `tests/` and, if they affect stored data, a `schema_version` bump.
