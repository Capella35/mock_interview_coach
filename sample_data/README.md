# sample_data/

Test inputs that are safe to commit: **fictional** resumes and LinkedIn exports (invented people, invented contact details) and **public** job descriptions copied from public postings, each with a note of its source URL and date. **Rule: real candidate data never goes here or anywhere in git** — that includes the project owner's own resume and LinkedIn export, which live in the gitignored `data/private/` folder. If you're unsure whether a file is fictional or public, it doesn't belong here.
